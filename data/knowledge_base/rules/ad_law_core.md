# 广告法核心条款

## 规则 R001：绝对化用语禁止
- **规则内容**：广告不得使用"国家级"、"最高级"、"最佳"等用语
- **法规依据**：《广告法》第九条第三款
- **严重程度**：高
- **违规示例**：
  - "全网最低价"
  - "行业第一品牌"
  - "国家级认证"
  - "世界领先技术"
  - "最佳选择"
  - "顶级品质"
  - "极品推荐"
  - "独一无二"
  - "无与伦比"
  - "史上最强"
- **关键词**：最佳、最好、第一、顶级、极品、国家级、世界级、最高级、最低、最强、最大、最优、首选、独家、唯一、独一无二、无与伦比、史无前例、前所未有、绝无仅有、首屈一指、出类拔萃、登峰造极、无以伦比、超级、终极、完美

## 规则 R002：虚假广告禁止
- **规则内容**：广告不得含有虚假或者引人误解的内容，不得欺骗、误导消费者
- **法规依据**：《广告法》第四条、第二十八条
- **严重程度**：高
- **构成虚假广告的情形**：
  1. 商品或服务不存在
  2. 商品信息与实际情况不符，对购买行为有实质性影响
  3. 使用虚构、伪造或无法验证的科研成果等作证明材料
  4. 虚构使用效果
  5. 其他欺骗误导情形
- **违规示例**：
  - "100%有效，无效退款"
  - "经临床验证，治愈率99%"
  - "百万用户好评如潮"（无实际数据支撑）
- **关键词**：100%、百分百、绝对、保证、承诺、无效退款、假一赔十、治愈率、有效率

## 规则 R003：功效断言禁止
- **规则内容**：广告不得含有表示功效、安全性的断言或者保证
- **法规依据**：《广告法》第十六条、第十八条
- **严重程度**：高
- **违规示例**：
  - "三天瘦十斤"
  - "一夜变白"
  - "纯天然无副作用"
  - "包治百病"
  - "立竿见影"
- **关键词**：三天见效、一周变白、无副作用、纯天然、包治、根治、立竿见影、速效、特效

## 规则 R004：国家机关使用禁止
- **规则内容**：广告不得使用或者变相使用国家机关、国家机关工作人员的名义或者形象
- **法规依据**：《广告法》第九条第二款
- **严重程度**：高
- **违规示例**：
  - "国家XX部委推荐"
  - "XX领导人视察指定产品"
  - "政府专供"
  - "军方特供"

## 规则 R005：国旗国徽使用禁止
- **规则内容**：广告不得使用或者变相使用中华人民共和国的国旗、国歌、国徽
- **法规依据**：《广告法》第九条第一款
- **严重程度**：高

## 规则 R006：社会公共利益保护
- **规则内容**：广告不得妨碍社会安定，损害社会公共利益
- **法规依据**：《广告法》第九条第五款
- **严重程度**：高

## 规则 R007：人身财产安全保护
- **规则内容**：广告不得危害人身、财产安全，泄露个人隐私
- **法规依据**：《广告法》第九条第六款
- **严重程度**：高

## 规则 R008：公序良俗保护
- **规则内容**：广告不得妨碍社会公共秩序或者违背社会良好风尚
- **法规依据**：《广告法》第九条第七款
- **严重程度**：高

## 规则 R009：淫秽色情内容禁止
- **规则内容**：广告不得含有淫秽、色情、赌博、迷信、恐怖、暴力的内容
- **法规依据**：《广告法》第九条第八款
- **严重程度**：高

## 规则 R010：歧视性内容禁止
- **规则内容**：广告不得含有民族、种族、宗教、性别歧视的内容
- **法规依据**：《广告法》第九条第九款
- **严重程度**：高

## 规则 R011：未成年人保护
- **规则内容**：广告不得损害未成年人和残疾人的身心健康
- **法规依据**：《广告法》第十条
- **严重程度**：高

## 规则 R012：贬低竞争对手禁止
- **规则内容**：广告不得贬低其他生产经营者的商品或者服务
- **法规依据**：《广告法》第十三条
- **严重程度**：中
- **违规示例**：
  - "比XX品牌好三倍"
  - "其他品牌都是垃圾"

## 规则 R013：非医疗类禁止涉及疾病治疗
- **规则内容**：除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语
- **法规依据**：《广告法》第十七条
- **严重程度**：高
- **违规示例**：
  - "治疗失眠"（非药品广告）
  - "预防感冒"（普通食品广告）
  - "抗癌"（保健品广告）

## 规则 R014：烟草广告禁止
- **规则内容**：禁止在大众传播媒介或者公共场所、公共交通工具、户外发布烟草广告
- **法规依据**：《广告法》第二十二条
- **严重程度**：高

## 规则 R015：广告可识别性
- **规则内容**：广告应当具有可识别性，能够使消费者辨明其为广告
- **法规依据**：《广告法》第十四条
- **严重程度**：低
