# 平台审核规范

## 规则 PL001：广告标识要求
- **规则内容**：广告应当具有可识别性，能够使消费者辨明其为广告
- **法规依据**：《广告法》第十四条
- **严重程度**：低
- **说明**：信息流广告应标注"广告"字样

## 规则 PL002：落地页一致性
- **规则内容**：广告内容应与落地页内容一致
- **法规依据**：平台规范
- **严重程度**：中
- **说明**：广告承诺的内容在落地页中应能兑现

## 规则 PL003：图片合规性
- **规则内容**：广告图片不得含有违规内容
- **法规依据**：平台规范
- **严重程度**：高
- **说明**：
  - 不得含有低俗、色情内容
  - 不得含有血腥暴力内容
  - 不得含有政治敏感内容
  - 图片应清晰，不得过度PS

## 规则 PL004：视频合规性
- **规则内容**：广告视频不得含有违规内容
- **法规依据**：平台规范
- **严重程度**：高
- **说明**：
  - 视频时长应符合平台要求
  - 不得含有诱导性内容
  - 不得含有虚假演示

## 规则 PL005：品牌一致性
- **规则内容**：广告中使用的品牌名称、LOGO应与实际品牌一致
- **法规依据**：平台规范
- **严重程度**：中

## 规则 PL006：价格真实性
- **规则内容**：广告中标注的价格应真实准确
- **法规依据**：平台规范
- **严重程度**：高
- **违规示例**：
  - 标注"原价999，现价99"但原价从未执行过
  - 价格与实际购买价格不一致

## 规则 PL007：促销活动规范
- **规则内容**：促销活动信息应真实、准确、完整
- **法规依据**：平台规范
- **严重程度**：中
- **说明**：
  - 应明确标注活动时间
  - 应明确标注活动规则
  - 不得使用模糊的促销用语
