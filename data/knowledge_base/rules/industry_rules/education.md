# 教育培训行业广告规则

## 规则 E001：升学保证禁止
- **规则内容**：教育、培训广告不得对升学、通过考试、获得学位学历或者合格证书作出明示或者暗示的保证性承诺
- **法规依据**：《广告法》第二十四条第一款
- **严重程度**：高
- **违规示例**：
  - "保上清华北大"
  - "考研包过"
  - "公务员考试100%通过"
  - "雅思保7分"

## 规则 E002：考试机构背书禁止
- **规则内容**：不得明示或者暗示有相关考试机构或者其工作人员、考试命题人员参与教育、培训
- **法规依据**：《广告法》第二十四条第二款
- **严重程度**：高
- **违规示例**：
  - "命题组老师授课"
  - "考官亲授"
  - "内部题库"

## 规则 E003：禁止利用受益者推荐
- **规则内容**：不得利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或者形象作推荐、证明
- **法规依据**：《广告法》第二十四条第三款
- **严重程度**：中
- **违规示例**：
  - "XX学员考上名校"（未经授权使用学员形象）
  - "XX教授推荐"

## 规则 E004：虚假师资宣传
- **规则内容**：不得虚构师资力量、教学成果
- **法规依据**：《广告法》第二十八条
- **严重程度**：高
- **违规示例**：
  - "100%名师授课"（实际并非全部名师）
  - "学员就业率100%"（无数据支撑）
